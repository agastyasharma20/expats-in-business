# Codebase audit (final polish, part 2)

Date: 2026-11-13 · Branch: feat/final-polish · Method: scripted scan of all 79 Server Actions (auth, Zod,
rate limit), grep for hard-coded chapter values and long files, `npm audit`, dev-server logs from the
e2e runs, and the earlier browser checks.

**Headline:** every Server Action authenticates and scopes writes to the owner or a permitted role.
No hard-coded Kraków, PLN, Europe/Warsaw or locale outside comments and legitimate logic. Findings are
consistency and hardening items, plus one invented fact.
