# Decisions (newest first)

- 2026-11-13 · Ambassadors have three tiers (global, country, city). The database enforces that each tier carries exactly the place fields it needs (CHECK constraints) and that a member has at most one open application per tier (partial unique index). Accepting creates the public Ambassador row in the same transaction; members can hide themselves. Only admins review (chapter leads cannot), and every decision is audited and notified.
- 2026-11-13 · Careers say plainly that most roles are volunteer roles. Paid roles are allowed by the model, but the only seeded one is labelled demo with placeholder terms; no real opening, salary or benefit is invented. A withdrawn role application can be sent again (same row, review fields cleared).
- 2026-11-13 · Country and chapter pages pick a line-art panorama by key (`landmark` column; components/landmarks). India (India Gate, Lotus Temple, Himalaya, Ganga) and Indore (Rajwada, riverside chhatris, river Khan) are original drawings, not traced. India and Indore are demo geography (isDemo) until EiB confirms real plans there.
- 2026-11-13 · The next published festival is spotlighted site-wide (header pill from xl widths, homepage banner) with a rotating conic-gradient ring: transform-only animation, stopped under reduced motion. Cultoura is EiB's real series (docs/FACTS.md); the seeded "Cultoura (demo edition)" is fictional and labelled so.
- 2026-11-13 · City votes reuse ChapterRequest. A vote for a city that already has a live or launching chapter is refused, votes are rate-limited (10 per hour, 20 per day) and the country must exist.
- 2026-11-13 · Polish and Ukrainian are full catalogues (all ~1,700 strings) marked `_status: "machine-translated, reviewed: no"` until a native speaker reviews them. Counted nouns use real ICU plurals with one/few/many/other (a test enforces few and many in every pl/uk plural). Tests also check that every placeholder of the English message survives in each translation and that every message is valid ICU. The developer-only `styleguide` namespace stays English on purpose.
- 2026-11-13 · Locale messages are deep-merged over English (`lib/i18n/merge.ts`): a key missing anywhere falls back to English instead of showing a raw key. The previous merge only covered top-level namespaces.
- 2026-11-13 · Emails go out in the recipient's saved language (`User.locale`, set in Settings or now also by the header language switcher for signed-in members), with links prefixed for that language. Internal team emails (help form, corporate enquiry) stay English.
- 2026-11-13 · Guides stay English (their statements are verified against official sources); each guide carries machine-translated pl/uk titles and summaries in frontmatter, shown with the label "machine-translated, not reviewed" and a note that the body is in English.
- 2026-11-13 · next-intl's default `timeZone` is the first live chapter's zone from the database (never hard-coded); explicit chapter zones still win where a page knows the chapter.
- 2026-11-13 · SEO: every indexable public page sets a canonical URL and en/pl/uk/x-default hreflang via `withAlternates`; sessions and festivals get generated 1200×630 social cards; guides publish Article JSON-LD (dateModified = last verified, citations = official sources); help and festival FAQs publish FAQPage. Bubble pages are now indexable (they were in the sitemap but marked noindex).
- 2026-11-13 · The festival page reads its public data through a shared cache (30 s, tag `events`) and streams only the viewer-specific parts (ticket, shifts, stall) in their own Suspense boundaries. The hero has a fixed minimum height shared with its skeleton and no entrance animation on the title (the LCP element). Result: LCP 1.0 s and CLS 0 (was 4.9 s / 0.25).
- 2026-11-13 · Lighthouse runs with the installed Google Chrome (`CHROME_PATH`): Playwright's Chromium produced NO_NAVSTART trace errors. Never run `next build` while a server is running from the same `.next`: the running server kept writing cached pages that referenced old CSS chunks, which looked like a performance regression.

- 2026-11-13 · Festivals are Events with `kind = festival`, not a separate model, so payments, waitlist, emails, QR check-in, Pulse and sponsor reports work unchanged. Festival-only data (programme, volunteer shifts, stall applications, FAQ) hangs off Event. Regular session lists (`/events`, homepage) show `kind = session` only; `/events/<festival>` redirects to `/festivals/<slug>`.
- 2026-11-13 · Group orders: `Ticket.quantity` (1 to the festival's `maxPerOrder`, at most 10; the database also enforces 1 to 20). One ticket and one QR code admit the party. All capacity maths sums party sizes; tier caps (`TicketType.capacity`) and early-bird ends (`salesEndAt`) are enforced inside the existing per-event row lock. Stripe is charged tier price × quantity, and the webhook only confirms if the paid total matches exactly. Waitlist promotion never splits a party.
- 2026-11-13 · Database CHECK constraints guard quantities, capacities, prices and time ranges, so impossible values are rejected even if application code is wrong.
- 2026-11-13 · Helpers shared by server actions live in `lib/festivals/manager.ts` (server-only), never in a `"use server"` file, where every export becomes a publicly callable endpoint.
- 2026-11-13 · Stall applications use the applicant's account email for contact (no extra personal data collected). Only organisers of that chapter and admins see it. Festival attendee CSV has names and party sizes, not emails.
- 2026-11-13 · The chapter preference is read from the Cookie request header, not `cookies()`: on Next 16.4 a server-action form posted before hydration re-renders the page and `cookies()` hits an internal invariant. Next upgraded to 16.4.6 (patch).

- 2026-11-12 · Security headers: a static CSP in next.config.ts replaces the planned nonce CSP in proxy.ts. Per-request nonces would make every page dynamic and defeat Cache Components/PPR, so scripts allow 'self' + 'unsafe-inline' (no eval in production), with object-src 'none', frame-ancestors 'none', base-uri 'self' and form-action limited to self, Stripe Checkout and Google sign-in. HSTS is sent only when APP_URL is https. Permissions-Policy now allows the camera for this origin: the old camera=() blocked the door QR scanner.
- 2026-11-12 · Abuse protection is per account, in Postgres: named buckets in lib/security/limits.ts (burst window + daily cap) for posts, reactions, reports, moderation, Bubbles, roulette and admin actions. Better Auth's limiter uses the same table (customStorage.consume) instead of process memory, so limits survive restarts and hold across instances. Every server action reloads the target row and re-checks permissions from the database; hidden form fields are never trusted.
- 2026-11-12 · Suspension: User.suspendedAt. Suspending deletes all sessions and roulette opt-ins; a Better Auth session.create hook refuses new sessions and getSessionUser treats a suspended account as signed out. Admins cannot suspend themselves or other admins, and the "admin" role cannot be granted from the UI (lib/admin/rules.ts).
- 2026-11-12 · Community moderation: a reported post is hidden for its reporter at once and for everyone after 3 distinct open reports (AUTO_HIDE_REPORTS), never on a single report (that would let anyone silence anyone). Moderator removal sets removedAt (kept for the audit trail) and notifies the author. Post text is stored as plain text after removing invisible and bidi-override characters; at most 3 links; the same text twice in 24 hours is rejected.
- 2026-11-12 · Feature flags and the site banner live in SiteSetting and are edited in /admin/settings (audited). Both are read through "use cache" with a tag and invalidated with updateTag, so the header costs no query per page and a change applies at once.
- 2026-11-12 · The Bubbles map is server-rendered SVG (d3-geo Equal Earth; world-atlas topojson tagged with ISO codes by scripts/build-map.ts; path precision 1 decimal): no map JavaScript, no tile requests. Counts under 5 are never shown; those countries get a different tint and the label "fewer than 5".
- 2026-11-12 · Joining a Bubble starts hidden from its member list (opt in with "Show me"). Coffee Roulette contact details (email) appear only after every member of a match accepts. Member Plus "priority matching" places Plus members first in the draw.
- 2026-11-12 · Session-bound pages under (member), (admin) and (provider) export `instant = false`; the layout-level flag alone still logged the dev "uncached data" error on each page.

- 2026-11-10 · Seed layering: real configuration (country, chapters, catalogues, plans, roadmap tasks) is `isDemo=false` and upserted. Everything fictional is `isDemo=true` and replaced by `demo:reset`. This deviates from the M4 prompt's "every seeded record isDemo=true" so a real install can keep its configuration.
- 2026-11-10 · Cached data loaders (`"use cache"`) must throw on failure; a non-cached wrapper catches and returns the empty state. Catching inside the cache would cache the failure.
- 2026-11-10 · Public pages animate with CSS keyframes (they run on first paint, need no hydration and ship no JS). Motion is only loaded by pages that use `m.*` components, inside `MotionProvider`.
- 2026-11-10 · The layout passes only the client namespaces to `NextIntlClientProvider`; pages with extra client needs (the styleguide) add their own provider.
- 2026-11-10 · Guides accept only official https sources (gov.pl, krakow.pl, zus.pl, knf.gov.pl, europa.eu) and must be re-verified within a year (tests enforce this). City-specific guides carry a `chapter` frontmatter field.

- 2026-11-10 · The locale comes from `next/root-params` (in lib/i18n/request.ts and the locale layout). No page awaits `params` and `setRequestLocale` is gone (deprecated by next-intl). This removes the "URL data outside Suspense" instant-navigation insight on every page. As a result `app/layout.tsx` is gone, so `[locale]` is the root layout again; URLs outside any locale use `app/global-not-found.tsx` (`experimental.globalNotFound`). The legal pages are three static routes sharing `LegalPageView` instead of `[slug]` (`dynamicParams` is not supported with Cache Components). The `[...rest]` catch-all sets `instant = false` because it only ever 404s.

- 2026-11-10 · Unbuilt nav destinations (Events, Members, Providers, Guides, Pricing, Sign in) render designed, noindex coming-soon pages with working actions, so the full navbar ships now and the crawler stays green. Each later milestone replaces its route.
- 2026-11-10 · Social and contact links come from config/facts.ts, read from the EiB Connect page on 9 Nov 2026 and recorded with sources in docs/FACTS.md.
- 2026-11-10 · The chapter preference is a first-party httpOnly cookie (eib-chapter, 1 year) set by a validated server action. It records a choice the visitor made, so it is treated as strictly necessary (see the cookie policy draft).
- 2026-11-10 · Legal pages render MDX with next-mdx-remote-client inside "use cache". Request APIs are unavailable there, so translations take an explicit locale, links use ExternalLinkBase and getPathname, and facts reach the MDX through scope and <ContactEmail />. The same pipeline is meant for the M4 guides.
- 2026-11-10 · 404 handling follows the next-intl pattern: a [...rest] catch-all under [locale], a pass-through app/layout.tsx and app/not-found.tsx. The (dev) route group became (tools) because next dev kept routing /styleguide to the catch-all.
- 2026-11-10 · Playwright uses 2 workers in CI. Six workers on one production server queued route prefetches behind Chrome's 6-connections-per-host limit, which stalled navigations.

- 2026-11-07 · Brand from the live site (docs/brand/BRAND.md): Deep Teal #093334, tint #C5E8EB and the real fonts Cabin + Nunito Sans replace the brief's starting values and Montserrat + Inter. The orange stays as "ember" for decoration, with #C2260C for one highlight button.
- 2026-11-07 · Logo: the original 3000 px raster is used (resized by scripts/brand-assets.mjs). It is **not** redrawn as SVG: it isn't a small raster, and a hand-traced "EB" would drift from the real artwork. Ask EiB for the vector source.
- 2026-11-07 · Buttons use 8 px radius, not the live site's square corners. Colour changes on hover are instant; only transform (press) and opacity animate.
- 2026-11-07 · /styleguide is available in development and demo mode (not only development) so CI's production build can e2e-test it. It is noindex.
- 2026-11-07 · cn is created with the custom token lists (lib/utils.ts); importing the bare "cn" package is a lint error.

- 2026-11-06 · i18n: next-intl with `localePrefix: "as-needed"` (English at /, /pl and /uk prefixed). The default locale comes from DEFAULT_LOCALE. pl/uk merge over en until M15.

- 2026-11-06 · Unconfirmed data lives in typed config/registries with a status, so placeholders are labelled automatically and real data replaces them with no component changes (docs/BUILD_PLAN.md §0).
